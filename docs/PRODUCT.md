# 产品与视觉基准

定位：面向公众的公开信息调查与事实核验工作空间。主流程是“提出疑问—发现线索—回到原文—对抗核查—说明依据与局限”。

优先还原原对话最后一张被确认的浅色首页图，避免迁移旧 Stitch 深色导航方案。内容背景 #F7F9FD、白色卡片、浅蓝点缀、海军蓝操作按钮。首页采用浅色左导航、大中文衬线标题、输入主区、四步流程、选题建议及右侧最近调查。

首版页面：真相工作台、发起核验、实时调查室、真相报告、档案馆、来源列表与设置。持续追踪只提供明确未实现的状态，关系图目前显示来源及未确认独立性，不假画传播关系。
