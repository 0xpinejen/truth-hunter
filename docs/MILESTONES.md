# 分阶段里程碑与验收矩阵

状态依据可重复检查，不以页面数量或动画完成度替代真实调查。原计划保留 Phase 0–5 顺序，优先让 Phase 1 的同一套页面承接 Phase 2 的真实数据。

| 阶段 | 可交付结果 | 验收门槛 | 当前状态 |
|---|---|---|---|
| Phase 0 · 基础 | 仓库核查、视觉基准、配置模板、迁移、Provider 契约 | 空目录无覆盖；数据库可迁移；接口解析、缺密钥及错误响应测试通过 | 已实现，真实连通性另列阻塞 |
| Phase 1 · 可交互 UI | 首页→创建→调查室→报告→档案 | 使用确认图设计语言；演示模式持续标识；SSE 事件可查看；引用跳转；1440px、390px 检查 | 首版已实现、验证；仍需用户视觉反馈 |
| Phase 2 · 真实调查 | 真实元宝→真实浏览器→原文→模型分析→SSE→阶段报告 | 本机真实 RequestId、查询记录、截图、时间、正文哈希、精确引文可追溯；取消、失败、超时、重启可恢复为部分报告 | 适配与编排代码已实现；真实验收未通过，缺凭证和可用公网 DNS |
| Phase 3 · 可信核验 | 原子声明、溯源、独立验证、反证、污染审计、证据裁决 | 原始源与转载分组；关系有依据；多域名不自动算独立；反证能进入裁决；注入测试不能改变执行边界；无证据返回 INSUFFICIENT | 未完成；当前只有反证查询、正文相同关系和引用校验，最终结论保守降级 |
| Phase 4 · 真相揭示 | 四幕报告、关系图、真实事件回放与分享 | 图线来自已确认关系；未知关系虚线；回放可对应持久化事件；分享产物注明局限 | 报告与原文引用首版已实现；关系图、回放、PDF/长图未完成 |
| Phase 5 · 参赛交付 | 回归、三项真实案例、部署、运行说明 | 三个真实案例可重复运行；无严重安全缺口；部署重启后可查历史；验收资料完整 | 测试和本地文档部分完成；不具备发布条件 |

## 优先级与下一步

1. **解除 Phase 2 阻塞**：由用户在本地 `.env` 配置元宝服务密钥、模型地址/模型名/密钥；解决代理 fake-IP DNS 导致公开来源被判非公网的问题。不得通过允许私网访问来“通过”测试。
2. **只跑一条真实消息**：最多 3 次搜索（最多两条普通查询＋一条反证查询），快速模式最多 3 页，深度模式最多 6 页，总时限 180 秒，最多两项并行任务。对每次实际成功和失败保留事实记录。
3. **审查证据链**：核对真实 SearchRun→Source→Snapshot→Evidence→Claim→Report。确认引用逐字存在、URL 是实际最终地址、截图不是占位图。
4. **实现 Phase 3**：增加出处提取、引用链和可审计关系；独立性未知时不能按独立信源计数；给出相关性、时效性、原始源和反证要求；通过人工复核或明确的事实核验规则，逐步开放非 INSUFFICIENT 最终裁决。
5. **用真实数据完善 Phase 4/5**：传播关系图、回放、导出、三个可重复案例和生产环境边界。

| 编号 | 检查 | 必备证据 | 当前 |

| L2 | 真实浏览器访问 | 公网 HTTPS、最终 URL、时间、正文和截图文件 | 被非公网 DNS 阻塞 |
| L3 | 声明拆解 | 真实模型输出＋结构化校验结果 | 未运行真实模型 |
| L4 | 逐字引文定位 | 已保存正文中的 Unicode 字符区间与哈希 | 规则单测通过，真实运行待验证 |
| L5 | 独立来源与反证 | 有依据的出处链、独立分组、支持/反驳证据 | 未实现完整核验 |
| L6 | SSE 与报告 | 真实步骤事件及相应报告引用 | 演示/API 测试通过，真实任务待验证 |
| L7 | 失败不伪装 | 缺凭证、429、访问失败、取消和超时的状态/局限 | 单测通过 |

## 定义“完成”

`COMPLETED` 在 fixture 模式中仅代表演示流程完成，绝不计入“完成核验”。真实模式当前最多为 `PARTIAL`，最终裁决为 `INSUFFICIENT`，直到来源独立性复核完成。状态、页面、导出都携带 `data_mode`，健康检查的“已配置”不代表“已连通”。
