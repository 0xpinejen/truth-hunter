# 本地版本安全边界

当前仅允许监听 127.0.0.1。没有用户身份、团队隔离或公网访问控制，不得按生产部署验收。CORS 只列出本机前端来源。

## 已实现

- 密钥只从后端环境读取；`.env`、依赖、SQLite、抓取文本与截图均忽略 Git 跟踪。
- 对元宝和模型调用不打印密钥及上游原始错误消息。
- 浏览器仅允许显式域名上的 HTTPS、443、无用户密码的 URL；DNS 任一地址非全球可路由则阻断。
- 每个网络请求/重定向都重新检查，禁止 POST、下载、ServiceWorker 和 JavaScript；不登录、不提交表单、不执行网页里的操作指令。
- 引文必须逐字存在于保存正文中；未知声明/证据引用被拒绝；源内容用 React 文本转义，不执行 HTML。
- 最多 2 项并发任务、3 次检索、快速 3 页/深度 6 页、总时限 180 秒，单页导航 20 秒，正文最多 80000 字符。
- 最终裁决在独立性和相关性复核完成前保留 INSUFFICIENT。

## 必须继续解决

1. **DNS 绑定风险**：当前先解析检查再由浏览器建立连接，存在 DNS 检查与浏览器解析不完全一致的时序风险。生产需要独立浏览器沙箱、强制出站代理和网络层禁止私网，并绑定/审计实际连接目的地址。应用层校验不能被当成完备 SSRF 防御。
2. **本机代理 DNS**：本次腾讯云解析结果 `198.18.7.215` 被规则拒绝。需要调整运行网络环境提供公开解析，不能为了演示直接允许保留地址或私网。
3. **提示词注入**：系统提示与引用规则是防御层，不能证明 LLM 已完全免疫网页注入。目前测试只证明模型不能靠输出未知引用或未经复核的意见形成最终裁决；需加入真实恶意网页与对抗评测。
4. **内容相关性**：引文匹配只证明文本存在，不证明它支持/反驳声明。当前不开放自动最终裁决；下一阶段需证据相关性/时效性与独立性复核。
5. **成本与存储**：没有配额计费仪表、token 成本硬上限、响应总字节硬上限或数据保留策略。浏览器字节流/内存/CPU 需进程级限制。
6. **生产依赖**：没有生产镜像、认证、授权、PostgreSQL 驱动验收、持久任务队列、恢复重试策略、内容版权/删除工作流。Docker Compose 尚未交付。

首轮保持失败可见，禁止把问题隐藏成已核验成功。安全测试通过的范围只覆盖 `tests/test_core.py` 中明确的输入集合。
